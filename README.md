# Cuaderno Quirúrgico · UEM

Sitio interactivo de seguimiento formativo de cirugía veterinaria, en español. Incluye siete procedimientos iniciales correspondientes a seis pacientes, fichas de siete apartados, atlas canino/felino, estadísticas, clasificación por nivel de participación, edición y nuevas fichas, exportación JSON/CSV e impresión PDF.

## Publicación en GitHub Pages

1. Crea un repositorio público llamado `cuaderno-quirurgico` en la cuenta de GitHub deseada.
2. Sube `index.html` y este archivo `README.md` a la rama `main` (en la raíz del repositorio).
3. En **Settings → Pages → Build and deployment**, selecciona **Deploy from a branch**, rama **main**, directorio **/(root)** y guarda.
4. El sitio estará disponible en `https://bdeveteuropea.github.io/cuaderno-quirurgico/` si utilizas la cuenta `bdeveteuropea`.

**Privacidad:** GitHub Pages es público. No introduzcas datos personales de propietarios ni identificadores de pacientes o historias clínicas. La información guardada con el formulario se almacena en el navegador (`localStorage`) y no se sincroniza automáticamente entre dispositivos. Exporta regularmente el archivo JSON para conservar una copia de seguridad.

**Nota:** el atlas de procedimientos es orientativo, no una lista exhaustiva de toda la cirugía veterinaria. Su indicador de experiencia no equivale a certificación de competencia.
